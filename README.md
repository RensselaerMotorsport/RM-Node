# RM-Node
**This is quite unfinished right now and will be updated**
CAN bus data aquisition and control nodes using stm32.
Currently the nodes are only for the f0 chip and use driver version 1.11.0.

## Installation
Install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html) and [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html)
Clone the respository into your workspace folder located at:
```C:\Users\*your username*\STM32CubeIDE\workspace_x.xx.x```
